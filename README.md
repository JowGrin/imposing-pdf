# imposing-pdf
A desktop PDF imposition and processing tool built with JavaFX and Apache PDFBox. Features booklet layout, N-up, Step &amp; Repeat, and core page operations

## Features

### Advanced Imposition & Layout
- **Booklet Creation:** Rearranges pages automatically for standard saddle-stitch booklet printing.
- **N-Up Imposition:** Combines multiple pages onto a single sheet (e.g., 2-up, 4-up).
- **Step & Repeat:** Duplicates a single page across a sheet layout for batch card or label printing.
- **Trim & Shift:** Adjusts alignment, margins, and handles trim/bleed settings.
- **Split Pages:** Divides a PDF into separate files according series (one from each series).
- **Define Size:** Standardizes or customizes page and sheet output dimensions.
- **Mix:** Interleaves and reorders pages from multiple sources.
- **Rotate:** Rotates selected pages or entire documents to match orientation requirements.


### Document Manipulation
- **Merge:** Combines multiple PDF files into one.
- **Split:** Divides a PDF into separate files or custom ranges.
- **Extract:** Pulls specified pages from a document.
